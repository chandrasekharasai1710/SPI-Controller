# 8-Bit SPI Master Controller in Verilog

Designed an 8-bit SPI Master supporting full-duplex communication using Verilog HDL, a configurable clock divider, and a four-state FSM.  
Implemented serial data transmission, reception, and chip-select control.  
Developed a self-checking testbench with directed test vectors to verify functional correctness.  
Simulated and debugged the design using Icarus Verilog and GTKWave.
